## ۱. اهداف کلیدی بازطراحی معماری

این سند معماری، پایه فنی برای حل دائمی تعارضات بصری و ارتقای وب‌سایت به یک تجربه سه‌بعدی سینمایی و تعاملی است.

### ۱.۱. لحظه امضای بصری: تبدیل هدر به سازه فضایی (Hero Metamorphosis)
- در بدو ورود کاربر (اسکرول ۰)، سایت به عنوان یک پورتال سازمانی فوق‌العاده مدرن و باکلاس ظاهر می‌شود: هدر، لوگو، تایپوگرافی معتبر، شعار، و دکمه‌های اقدام شفاف.
- با اولین اسکرول، قاب هدر کالبد فیزیکی و عمق سه‌بعدی به خود می‌گیرد؛ به یک دروازه یکپارچه معماری تبدیل می‌شود و دوربین با حرکتی سینمایی و روان از درون آن عبور می‌کند تا پردیس نوآوری اروم‌سیما آشکار شود.

### ۱.۲. حل اصولی تداخل DOM و لایه سه‌بعدی (Spatial Docking Architecture)
- **مشکل معماری قبلی:** کارتهای حجیم با شفافیت کم (۸۵٪ مات) و بلور سنگین تمام عرض صفحه را می‌پوشاندند و اشیای سه‌بعدی پشت صحنه مخفی می‌ماندند.
- **راهکار جدید (طرح پهلوبندی متقارن و هوشمند - Asymmetric Docking):**
  1. لایه محتوای متنی در دسکتاپ به یک ستون هوشمند در سمت راست (سمت خوانش زبان فارسی) با عرض حدود ۳۸٪ اختصاص می‌یابد.
  2. ۶۲٪ باقی‌مانده سمت چپ کاملاً برای نمایش و مانور سازه‌های سه‌بعدی (پاویون‌های خدمات، سکوهای پروژه‌ها، برج‌های استراتژی) باز و بدون مانع است.
  3. لایه نگهدارنده DOM از `pointer-events: none` استفاده می‌کند؛ تنها کارت‌های متنی و دکمه‌ها دارای `pointer-events: auto` هستند. این کار دسترسی مستقیم موس و Raycaster به اشیای سه‌بعدی را آزاد می‌کند.
  4. تعامل دوطرفه (Bi-directional Hover): هاور روی سازه سه‌بعدی، کارت متنی متناظر را روشن می‌کند و بالعکس.

### ۱.۳. بهینه‌سازی عملکرد و حذف رندرهای غیرضروری React
- حذف فراخوانی `setScrollProgress(p)` در هر فریم اسکرول.
- استفاده از `scrollProgressRef` که به صورت مستقیم در متد `useFrame` از طریق `maath/easing.damp3` پردازش می‌شود.
- نرخ فریم پایدار ۶۰FPS بر روی تمام دستگاه‌ها بدون درگیر کردن پردازشگر React Virtual DOM.

## ۳. قرارداد دوربین و ایستگاه‌های ۵ گانه صفحه اصلی

```typescript
export const WAYPOINTS = [
  // ایستگاه ۰: هدر شرکتی و دروازه نکسوس (ورود)
  { pos: [0, 5.0, 15.0], target: [0, 2.0, 0.0], fov: 45 },
  // ایستگاه ۱: بال راست - پاویون‌های خدمات ۳۶۰ درجه
  { pos: [6.5, 3.2, -18.0], target: [-1.5, 1.8, -32.0], fov: 48 },

  { pos: [0, 3.2, -135.0], target: [0, 2.2, -165.0], fov: 45 },
```

## ۴. استراتژی تطبیق موبایل و دسترسی‌پذیری (Mobile & A11y Strategy)

1. **مدیریت ابعاد و Touch در موبایل:**
   - زاویه دید دوربین (`FOV`) در موبایل به صورت داینامیک تا ۵۸ درجه افزایش می‌یابد تا سازه‌های سه‌بعدی حتی در نمایشگرهای عمودی بریده نشوند.
   - چیدمان نامتقارن دسکتاپ در موبایل به صورت کارت‌های فشرده شفاف در پایین صفحه قرار می‌گیرد.
2. **پشتیبانی از `prefers-reduced-motion`:**
   - در صورت فعال بودن این گزینه در سیستم‌عامل کاربر، حرکات دوربین و چرخش سازه‌ها متوقف شده و رندرینگ به حالت پس‌زمینه نوری مینیمال تغییر وضعیت می‌دهد.
3. **دسترسی کامل کیبورد و SEO:**
   - تمام دکمه‌ها و لینک‌ها با استفاده از تگ‌های استاندارد `<a>` و `<button>` پیاده‌سازی شده و از قابلیت تب‌بندی کیبورد (`Focus Outline`) بهره‌مند هستند.
