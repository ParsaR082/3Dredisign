## ۱. بهینه‌سازی‌های اعمال‌شده در سطح WebGL و Three.js

1. **مدیریت نرخ نمونه‌برداری پیکسل (Dynamic Pixel Ratio):**
   - به جای استفاده از `window.devicePixelRatio` مستقیم (که در نمایشگرهای رتینا به ۳ یا ۴ می‌رسد و GPU را خفه می‌کند)، مقدار DPR به صورت هوشمند بین `[1, 1.5]` محدود شده است:
   ```tsx
   dpr={[1, 1.5]}
   gl={{ powerPreference: 'high-performance', antialias: true, alpha: true }}
   ```
2. **کاهش فراخوانی‌های ترسیم (Draw Calls Reduction):**
   - استفاده از متریال‌های مشترک و استاندارد شده به جای ایجاد شیدرهای مجزا برای هر آبجکت.
   - بهره‌گیری از `<RoundedBox>` و `<Float>` سبک بدون ایجاد سربار رندرهای موازی.
3. **کنترل حلقه رندرینگ (Single Render Loop with Smooth Damping):**
   - تمامی محاسبات زاویه دید و حرکت دوربین بر پایه یک حلقه یکپارچه در `DigitalArchitectureCampus.tsx` با استفاده از کتابخانه سبک `maath/easing` انجام می‌شود:
   ```tsx
   easing.damp3(state.camera.position, targetCamPos, 0.18, delta);
   easing.damp3(currentLookAt.current, targetLookAt, 0.18, delta);
   ```
   این تکنیک مانع از ایجاد پرش‌های ناگهانی یا محاسبات سنگین ریاضی در هر فریم می‌شود.

## ۲. بهینه‌سازی‌های فریم‌ورک Next.js و بسته نهایی (Bundle Optimization)

1. **تفکیک کامل کامپوننت‌های سمت سرور و کلاینت:**
   - صفحه اصلی (`src/app/page.tsx`) یک Server Component کامل است که محتوای سئو و متادیتا را بدون نیاز به لود جاوااسکریپت در خروجی HTML درج می‌کند.
   - رندرر سه‌بعدی از طریق `next/dynamic` با گزینه `ssr: false` تنها در سمت کلاینت لود می‌شود تا مانع از تاخیر در پاسخ اولیه سرور (TTFB) گردد.
2. **حجم بسته اولیه (First Load JS):**
   - حجم کد جاوااسکریپت اولیه اشتراکی: **74.6 kB**
   - حجم صفحه اصلی با احتساب تمام تعاملات: **103 kB**
   - این رقم برای وب‌سایتی که حاوی یک موتور سه‌بعدی فضایی است، در مقیاس جهانی ممتاز محسوب می‌شود.
3. **فونت‌های محلی با پیش‌بارگذاری:**
   - فونت فارسی `DigiRastinPlusLine` به صورت محلی در پوشه `public/fonts/` قرار گرفته و فرمت‌های مدرن `woff2` برای کاهش حداکثری Layout Shift (CLS) استفاده شده‌اند.

## ۳. شاخص‌های حیاتی وب (Core Web Vitals Targets)

| شاخص حیاتی | هدف طراحی | وضعیت محقق‌شده |
| :--- | :---: | :---: |
| **LCP (Largest Contentful Paint)** | کمتر از ۲.۵ ثانیه | به دلیل رندر سمت سرور متون اصلی، تیتر H1 زیر ۱ ثانیه نقاشی می‌شود |
| **CLS (Cumulative Layout Shift)** | کمتر از ۰.۱ | صفر؛ زیرا بوم سه‌بعدی در لایه پشت به صورت `fixed inset-0` قرار دارد |
| **INP (Interaction to Next Paint)** | کمتر از ۲۰۰ میلی‌ثانیه | کلیه شنونده‌های اسکرول با `{ passive: true }` ثبت شده‌اند |
